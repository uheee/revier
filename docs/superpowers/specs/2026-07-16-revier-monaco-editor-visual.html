Revier Monaco 编辑器最终视觉稿

最终方案融合 IDE 工具感与 Review 语义，完整支持浅色/深色主题。左栏保留全部筛选，代码区使用 Monaco 原生 Diff 和 Minimap，作者信息进入独立 AuthorRail，底部状态栏承载编码与语言交互。

关键视觉规则

IDE 工具结构

保留标签、命令入口、Minimap 和底部状态栏。顶部不重复显示语言和 Minimap 开关。

连续块边界

旧侧深红、新侧深绿，teal 只绘制块首和块尾；多行块内部不出现横线。

外置 AuthorRail

作者列位于 Monaco 最右侧，严格服从块高度；空间不足时显示 `…` 并向左展开完整列表。

筛选区保留

分支、时间、作者、提交信息、文件规则和变更文件列表继续位于左栏。

完整主题

浅色和深色覆盖整个工作台、弹层和状态栏，不使用浅色外壳与深色编辑器拼接。

草稿语义

首次编辑后隐藏真实块边界和 AuthorRail，右栏显示临时草稿不提供归因。
