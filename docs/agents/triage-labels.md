# Triage Labels

engineering skills 使用五个 canonical triage roles。本文档记录这些 role 和本仓库 issue tracker 中实际 label 字符串之间的映射。

| Label in mattpocock/skills | Label in our tracker | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage` | `needs-triage` | 需要维护者先评估和分类 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可以交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人类开发者处理 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个 role，例如 “apply the AFK-ready triage label”，应使用上表右侧对应的实际 label 字符串。

如果本仓库未来已有不同的 GitHub label 体系，只需要修改上表右侧 `Label in our tracker` 列。
